# Timing closure

## Surviving documented result

The lost original 16 nm implementation was documented at **228 MHz**. Raw sign-off STA evidence no longer survives.

## Current rerun evidence standard

For each implementation commit: target period, actual clock definition, uncertainty/derates, setup and hold corners, WNS, TNS, unconstrained-path count, top critical paths, stage (post-synth/post-CTS/post-route/sign-off), tool/version, and any exceptions.

The 228 MHz value should remain qualified until the original design/report is recovered or a new implementation independently reaches a defensible measurement.
