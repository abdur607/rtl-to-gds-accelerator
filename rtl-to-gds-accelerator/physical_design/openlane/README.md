# Public OpenLane/OpenROAD reproduction path

This configuration is a legally shareable public flow for the reconstructed ARX surrogate. It is **not** the lost 16 nm commercial flow and cannot be used as evidence for the historical 228 MHz result.

Run with a locally installed compatible OpenLane release and open PDK, then copy concise report exports into `results/`. Do not commit the PDK, standard-cell libraries, full run database, or licensed binaries.
