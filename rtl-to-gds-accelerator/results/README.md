# Physical-design results evidence

This directory separates the lost original 16 nm result from the current public reproduction flow.

- `timing/HISTORICAL_RESULT.md`: qualified surviving 228 MHz result for the lost original cryptographic implementation.
- `signoff/HISTORICAL_RESULT.md`: qualified surviving statement that DRC/LVS issues were resolved.
- `synthesis/reference_model_pytest.*`: current executable model-test evidence for the public ARX surrogate.
- `ppa_template.csv`: empty normalized schema for current report-derived PPA data.
- `area/`, `power/`, `congestion/`, `layout/`: current rerun artifacts only.

Never place invented WNS/TNS, area, power, DRC/LVS counts, or layout images here to replace the lost reports.
