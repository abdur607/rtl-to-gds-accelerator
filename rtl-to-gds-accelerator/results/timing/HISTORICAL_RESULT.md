# Surviving timing result

The surviving project documentation records an achieved implementation frequency of **228 MHz** for the lost **16 nm FinFET cryptographic core**. The sign-off timing report and exact corner/constraints were lost.

This number is retained only as a surviving documented result. It is **not** attributed to `rtl/arx_permutation_core.sv`, the public OpenLane flow, or any newly generated report unless an independently rerun implementation demonstrates the same result under a documented environment.
